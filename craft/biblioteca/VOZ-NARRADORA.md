# Narrator voice sheet (synthetic voice)

The same synthetic voice is used for every video, so the narrator always sounds like the same person.
This file is read by `engine/voz-preparar.py` (the `texto` step), which pastes the voice name and description into the recording instructions.

**Voz:** Aoede.

**Descripción de la voz:**
```
Mujer mexicana de unos 30 años, contando una historia super interesante desde el comedor de su casa. No es locutora ni está leyendo: está contando algo que le interesa, con emocion en lo que cuenta. Voz media-grave, cálida, un poco rasposa y con aire, nada pulida. El tono nunca es fijo: sube cuando algo le da gracia, baja y se vuelve más suave cuando confiesa algo, y acelera un poquito cuando se emociona. Ritmo de plática real, con frases que se pegan entre sí y micro pausas irregulares donde respira o piensa. Se le escucha una pequeña inhalación antes de empezar y entre ideas, y suelta un "ay" o un "pues" de forma natural, sin teatro. Al principio se le nota una ligerísima carraspera, como de garganta recién despierta, que se le quita al hablar. Se ríe con la voz en algunas palabras, sin carcajada. La "s" es suave, las vocales un poco alargadas cuando enfatiza, acento chilango natural. Nada de dicción perfecta, nada de entonación de anuncio, nada de voz de asistente. Tiene que ser una voz muy emocionada contando las cosas
```

ElevenLabs best practices (model, tags, pauses, pronunciation) are in `ELEVENLABS-BUENAS-PRACTICAS.md`, in this same folder.
